# MLOps Iris Classifier Version A+B (Resolved)

A sample ML project used to demonstrate Git-based version control workflows in an MLOps context.

The project trains an Iris flower classifier using a Random Forest model and produces a classification report and saved model artifact.

## Version history

- Version A: alternate project description for the demo branch.
- Version B: alternate title and project summary for the demo branch.
- Final resolved version: combined, clear project documentation.

## Project goal

The goal of this project is to train a model on the Iris dataset, evaluate its performance, and save the trained model for later use.
